# Steel and State

A planning vault for a multiplayer Factorio: Space Age mod collection about government, corporations, work, research, and physical trade.

**Design stage.** This repository contains notes and pseudocode, not a playable mod. Rules, numbers, dependencies, and release packaging are deliberately loose.

Read the [illustrated feature overview](FEATURES.md) for the player-facing vision, or start at [Home](Home.md) for the planning vault. Current direction is tracked in [Decisions](planning/Decisions.md); unresolved choices live in [Open Questions](planning/Open%20Questions.md).

## Open in Obsidian

Open this repository folder as a vault using Obsidian's **Open folder as vault** option, then open `Home.md`. The repository itself is the vault; it is separate from the Codex memory vault. No community plugins are required. Markdown links connect the notes for navigation, backlinks, and graph view. Obsidian's personal workspace state is ignored by Git.

Local folder: `/home/vile/Projects/Mods/Factorio/steel-and-state`

## Local Git workflow

The public repository is [SilverSix311/steel-and-state](https://github.com/SilverSix311/steel-and-state). The local `main` branch tracks `origin/main`. Review changes with `git status` and `git diff`, then commit selected files with a descriptive message and push when intended. Do not store credentials or tokens here. Project licensing remains undecided.

## Contents

- `design/`: current gameplay notes.
- `architecture/`: conceptual module boundaries and pseudocode; no implementation commitments.
- `planning/`: decisions, questions, roadmap, and new-note template.
- `research/`: dated references and unverified dependency candidates.
- `archive/`: historical brainstorm, retained without treating old recommendations as current decisions.
- `steel-and-state-logo.png`: existing project logo, preserved in place.

No project license has been selected. Existing or future third-party assets require their own attribution and license review before reuse/publication.
